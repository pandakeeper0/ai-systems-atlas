# Concepts

Compact cards for named concepts, principles, paradoxes, and other reusable ideas that are useful across multiple topics.

These are not substitutes for topic pages. A concept card should stay focused on the concept itself: its English name, core meaning, origin, closely related concepts, and why it is useful.
