# Knowledge

Durable knowledge lives here, organized first by **domain** rather than by capture workflow.

## Domains

- [AI](ai/README.md) — agents, harnesses, models, evaluation, infrastructure, product design, and concrete AI systems.
- [Mathematics](mathematics/README.md) — mathematical foundations organized by discipline.
- [Principles & Ideas](principles-and-ideas/README.md) — named, reusable principles, paradoxes, laws, effects, and criteria that can cut across domains.

## Organization principle

The repository root represents the **knowledge-production workflow** (capture, sources, learning, briefs, questions). This directory represents the **knowledge itself**.
